## 2026-10-07 - Unsafe Property Lookups and DOM Method Clobbering in Client-Side State
**Vulnerability:** Unguarded property lookups on translation/authority dictionaries (`AUTHORITIES[key]` and `ES[key]`) and direct indexing of `form.elements[key]` during draft restoration permitted prototype properties (`toString`, `valueOf`) and DOM methods (`reset`, `submit`) to bypass default fallbacks and pollute element properties.
**Learning:** In JavaScript, `obj[key]` evaluates to inherited properties on `Object.prototype` when `key` is a prototype function name (e.g. `"toString"`), which evaluates as truthy and prevents default fallback logic (`|| DEFAULT`). Similarly, `form.elements[key]` returns inherited HTMLFormElement methods if `key` matches a form method name.
**Prevention:** Use `Object.prototype.hasOwnProperty.call(obj, key)` for dictionary lookups and `form.elements.namedItem(key)` with strict `instanceof` checks (`HTMLInputElement`, `HTMLSelectElement`, `HTMLTextAreaElement`, `RadioNodeList`) before populating form values from user or local storage input.
